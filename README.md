# 明堂图 · 三维经穴骨度定位模型 v1.0

> 361 个经穴，每一个都标出它凭什么站在那个位置。

一个单文件的三维人体经穴模型。Three.js 内联、无依赖、无构建，双击 `index.html` 就能打开，断网也能跑。

「明堂」是经穴图的古称。孙思邈《千金要方》中有《明堂三人图》——仰人、俯人、侧人；本模型的正视 / 背视 / 侧视三档预设，就是这个传统的三维延续。

---

## 为什么做这个

常见的三维经穴模型，坐标大多是「等分插值」出来的：知道某经从肩走到手，就把中间的穴位均匀摊开。看起来整齐，但**没有一个位置站得住**——你无法回答「手三里凭什么在这里」。

这个模型换了个做法：**每个穴位的位置都要能反算回一句古法描述**（如「肘横纹下 2 寸」「平第 11 胸椎棘突下，旁开 1.5 寸」），再叠加骨性标志校核。算不出来的，就老实标成「示意」。

## 四级可信度

| 级别 | 含义 | 视觉 | 穴数 |
|---|---|---|---|
| **实定位** | 按骨度分寸或骨性标志算出，可复算、可校核 | 实心球 | **229（63.4%）** |
| 待重建 | 有寸数可抽，但缺对应骨性几何 | — | 0 |
| 近似 | 仅有段落约束 | — | 0 |
| **示意** | 落在体模没有几何的部位（手足末端 / 头面五官），只表大致区域 | 空心笼 | **132（36.6%）** |

229 穴的构成：四肢主干 92 + 脊柱组 53 + 胸肋 26 + 躯干旁开 43 + 肩带 12 + 骨盆 3。

跨级之间的经络连线画成**虚线**——它的意思是「这两端之间没有可信坐标，中间是直线硬接的」，不是真实走行。

## 边界（比精度数字更重要）

这一节请务必读完再看那个 63.4%。

1. **体模是简化的标准体模，不是真人扫描。**「实定位」指在该体模上按骨度分寸 / 骨性标志算得的位置——可复算、可校核，但**不是解剖测量值**。
2. **132 穴为示意级，不参与精度声明。**它们是把手足末端与头面部位画成大致区域，不用来取穴。
3. **掌跖骨与颅骨有意不建几何。**为几十个穴重造一整只手，性价比不如标成示意级；而把头做成一个球是有意的简化，硬做眼耳鼻口，只会把「不确定」包装成「精确」——这比诚实标示意级更糟。
4. **体模本身有已知比例偏差**：脊柱腰骶偏细、胸腹交界处有台阶、肩部收窄、髋部比腰细约 0.56 寸、下肢整体偏低约 8 寸。这些都记在工程报告里，未修（改一处要重算几十个穴）。
5. **不用于临床取穴。**要精确取穴，请查 GB/T 12346《腧穴名称与定位》。

## 怎么用

- **拖拽**旋转，**滚轮**缩放
- **点击穴位**：看到定位描述、寸数换算、所属经脉与病候
- **左上勾选**：按经脉显隐
- **右上**：正视 / 背视 / 侧视 / 复位
- **只看已重建**：把示意级淡化到背景，专注 229 个实定位穴
- 琥珀编号表示该处有多个穴位重合，可点开选组内穴

## 数据与方法

- 穴位数据 361 条（含左右对称前的单侧定义），源自原设计数据集
- 定位方法：骨度分寸法（十二经骨度）＋ 骨性标志（椎节表、十二对肋骨、肩胛冈与肩峰、锁骨、髂前上棘、耻骨联合）
- 分段寸长：横向 1 寸 = 0.0233；纵向脐上 1 寸 = 0.0158、脐下 1 寸 = 0.0200
- 渲染：Three.js r149（内联），单文件，无外部请求
